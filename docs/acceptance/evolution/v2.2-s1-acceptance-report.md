# V2.2 S1 一系统一 MCP 结构纠偏验收报告

> 日期：2026-10-22  
> 状态：实现完成 / 用户门禁待执行

## 决策

Product A、Product B 是两个独立业务系统，每个系统提供一个完整 MCP。平台不再建设跨系统标准业务
能力层，不维护统一 Capability ID、业务 Schema、业务权限名称或 A/B 语义一致性测试。

## 已实现

- 新增 ADR-027 与 `22-V2.2-一系统一MCP架构.md`。
- MCP 开发根改为直接包含 `product-a-mcp/`；Schema、业务逻辑、MCP Server、stdio 和测试全部内聚。
- 删除 MCP 仓旧 `domains/data-quality`、`servers/demo-product-a` 和根级旧测试目录。
- Product A Tool 删除跨系统 `capabilityId/contractVersion/requiredPermission` 元数据。
- 主平台 stdio 集成测试删除 Capability Catalog、Plugin Runtime、旧 Adapter 及 A/B 语义对比依赖。
- 主仓已删除 `adapters/domains/skills/templates`、Plugin SDK/Runtime、Capability 兼容包和 E0–E5
  旧回归链路；Agent Server 组合根不再扫描本地业务代码，部署包也不再携带插件。
- 管理状态接口从 `/plugins`、`/capabilities` 调整为 `/mcp/servers`、`/mcp/tools`。

## 静态验证

- 新增/修改 JavaScript 测试通过 `node --check`。
- 新增 JSON 配置可解析。
- 两仓 `git diff --check` 通过（CRLF 转换提示不影响检查）。
- 引用扫描确认 MCP 当前源码不再引用旧 `domains/servers` 包和跨系统 Capability 元数据。
