## 1. 变更流程

任何对 ADR-001—008、ADR-014—015 的变动须明确说明“被改变的用户约束、原因、影响模块、迁移策略和新增测试”，而不是默默改代码。  
新增方案如改变 Capability 输入输出，必须增加版本，更新 Catalog、A/B Contract Tests 与 API 文档。

## 2. 当前尚需在 POC 定版

- Deep Agents 官方参数及 TS 版本；模型 Provider 选择，Skills Middleware/Backend 映射细节。
- `createDeepAgent()` 的可复用缓存策略、并发运行、Thread Checkpointer 兼容性。
- Ant Design X 各组件、SDK 可用 API 与相关 `@ant-design/x-*` 版本。
- 独立 Web 实际身份体系，iframe 短期授权票据具体交换流程。
- HTTP/Local Plugin Driver 的错误重试规则、正式发布插件的审核机制。

## 3. 不得回退的简化原则

**产品独立部署 != 代码为每个产品复制一份。**  
**插件自动挂载 != 为所有用户自动授权。**  
**Skills != 业务执行插件。**  
**Agent 统一语义 != 不同产品必须返回相同数值。**  
**会话在单实例内连续 != 跨 A/B 共享会话。**
