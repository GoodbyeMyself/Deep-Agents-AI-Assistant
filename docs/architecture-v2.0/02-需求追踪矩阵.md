## 平台必备但不直接属于原始 17 条的工程能力

| 工程能力                     | 为什么需要                 | 阶段      |
| ---------------------------- | -------------------------- | --------- |
| Plugin Loader 自动发现挂载   | 快速复用现有业务系统能力   | **M1 P0** |
| Capability 版本及契约测试    | 防止同名不同义造成业务错误 | M1 P0     |
| Deep Agents 公开扩展接口验证 | 避免重写 Harness           | M0 P0     |
| 独立 Web 模式                | 模型、会话和插件最小管理   | M3 P0     |
| 两个模拟产品独立部署         | 验证无产品身份耦合         | M5 P0     |

## 非功能验收

- 授权：越权执行 100% 被拒绝（测试集）；输出无测试敏感字段。
- 契约：两插件必须均通过共享契约测试；错误码与 `partial` 行为一致。
- 稳定性：能恢复同实例会话、可取消 Run、SSE 事件顺序可识别。
- 证据：来自工具的统计结果包含查询范围与时间；无来源时明确不足。
- 可维护性：不修改 Agent Factory，仅安装/更换适配插件即可通过相同业务测试。
