## 变更基线记录

### V2.0 / 2026-10-13

- 由“通用 AI Agent 平台”收敛到“企业业务智能体集成框架”。
- 明确四个核心业务目标：Capability、Policy、Context、Evidence；**Plugin 自动挂载保留为核心扩展机制**。
- 去掉面向 OpenClaw 式产品生态的高优先级计划：插件市场、多渠道 Gateway、跨实例会话和复杂通用配置。
- 重新编写 M0～M5；允许从新版 M0 重做，但要求 Codex 保护未授权文件和数据。

## 未来变更流程

新增关键技术选型或修改核心契约时，提交一个独立 ADR：问题→备选→决定→依赖影响→迁移/回滚→测试要求。不得在某个阶段悄悄扩大范围。
